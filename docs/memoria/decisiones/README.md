# Decisiones durables

Esta carpeta registra únicamente decisiones durables: elecciones vigentes que condicionan arquitectura, seguridad, producto, operación o tareas posteriores. No crea un registro para resultados temporales, investigaciones sin decisión, cambios puramente mecánicos ni detalles que ya estén explicados mejor en otra nota.

Al tomar una decisión durable, crea un archivo Markdown con fecha y título. Copia los encabezados siguientes y reemplaza las oraciones explicativas por los hechos, alternativa y efectos de esa decisión.

```markdown
# AAAA-MM-DD — Título de la decisión

## Contexto
Explica los hechos verificados que motivaron la decisión y las restricciones relevantes.

## Decisión
Describe la alternativa elegida de manera concreta y vigente.

## Consecuencias
Enumera beneficios, costos, riesgos y restricciones que deberán respetar tareas posteriores.

## Documentos relacionados
Incluye enlaces Markdown relativos a las notas de memoria afectadas.
```

Los enlaces del registro deben ser Markdown relativos y llevar a las notas afectadas; así se puede actualizar la memoria de cada dominio junto con la decisión que la motivó.
