# Pendientes de calidad de FutFinder

Revisión: 2026-09-24. Base de código contrastada: `5d97f38` después de `git pull`.

Este es el listado único para priorizar arreglos de Inicio, Chat, Perfil, Avisos, Ajustes y TrueScore. **Ningún ítem de esta lista está corregido por este documento.** Los casos C01–C10 provienen de [la auditoría de chats y notificaciones](ERRORES_CHATS_NOTIFICACIONES_2026-09-23.txt), que contiene los pasos y las pruebas de reproducción. Los casos nuevos se detectaron al revisar el flujo de datos del código; donde falta una prueba de interfaz o de dos sesiones, se indica.

Prioridades: **P1** afecta lectura, privacidad, avisos relevantes o acciones con consecuencias no informadas; **P2** produce datos o acciones incorrectas; **P3** es una inconsistencia de menor impacto. La prioridad no afirma que el fallo haya ocurrido en producción.
